## ¿Por qué aprender Backend con Go?

Golang es uno de los lenguajes más demandados para el desarrollo de servicios backend y herramientas DevOps. Dominar su ecosistema permite crear aplicaciones de alto rendimiento y comprender el funcionamiento interno de cualquier framework basado en Go.

## Lo que aprendí en el curso

Durante el curso construí aplicaciones reales con Go, utilizando únicamente las herramientas nativas del lenguaje, aplicando arquitectura limpia y buenas prácticas para desarrollar APIs REST profesionales.

### Fundamentos del Backend

- **HTTP y servidores**: Creación de servidores HTTP nativos, rutas, handlers y middlewares.
- **Manejo de solicitudes**: Procesamiento de JSON, query params, path params y body.
- **Manejo de errores**: Enfoque idiomático con errores explícitos, *Sentinel Errors* y respuestas con [RFC 7807](https://www.rfc-editor.org/rfc/rfc7807).

### Arquitectura limpia y patrones de diseño

- **Clean Architecture**: Separación por dominios, casos de uso, handlers y adaptadores.
- **Repository Pattern**: Abstracción de la capa de persistencia para mayor testabilidad.
- **Domain Driven Design**: Modelado de entidades, reglas de negocio y lógica central.
- **Organización del proyecto**: Estructura escalable y mantenible para APIs profesionales.

### Persistencia de datos

- **PostgreSQL**: Diseño de esquemas, migraciones y consultas SQL.
- **SQLC**: Generación de código Go type-safe a partir de consultas SQL.
- **Redis**: Almacenamiento en caché y *Token Store* para gestionar sesiones y tokens.

### Seguridad y autenticación

- **JWT**: Generación, validación y renovación de tokens.
- **Argon2id**: Hashing seguro de contraseñas.
- **Autenticación y autorización**: Flujos de login, protección de rutas y control de acceso.
- **Gestión de tokens**: Almacenamiento y revocación con Redis.

### Calidad, validación y observabilidad

- **Validaciones**: Uso de `go-playground/validator` (Validator V10) para validar datos de entrada.
- **Manejo de errores centralizado**: Respuestas consistentes y trazables.
- **Logging**: Registro estructurado para depuración y monitoreo.
- **Buenas prácticas**: Código limpio, reutilizable y preparado para producción.

## Resultados al finalizar el curso

- Construí APIs REST profesionales con Go de forma nativa, sin depender de frameworks.
- Comprendí cómo diseñar aplicaciones escalables aplicando arquitectura limpia y buenas prácticas.
- Adquirí experiencia con PostgreSQL, Redis, SQLC, JWT, Argon2id y validaciones.
- Desarrollé una base sólida para postularme a posiciones como **Backend Developer**, **Go Developer** o **Software Engineer**.
