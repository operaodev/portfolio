## Lo que aprendí en el curso

Completé el curso con el objetivo de entender cómo se estructura un programa en Go y recorrer cada uno de los conceptos cruciales del lenguaje, construyendo las bases sólidas necesarias para proyectar este conocimiento hacia cualquier área profesional.

Go es un lenguaje de tipado estático, con una sintaxis simple y un modelo de concurrencia nativo que lo hace ideal para backend, DevOps, herramientas de CLI, networking y cloud. A lo largo del curso trabajé con ejemplos reales enfocados en código limpio y listo para desplegar.

### Introducción y fundamentos de Golang

Partí desde cero, comprendiendo la filosofía del lenguaje, su tipado estático y la estructura básica de un programa en Go.

- Instalación y configuración del entorno
- Estructura de un programa y punto de entrada
- Variables, constantes y tipos primitivos
- Operadores y conversiones de tipos

### Tipos compuestos y estructuras de control

Aprendí a modelar datos y a controlar el flujo del programa con las construcciones propias de Go.

- Arrays, slices y mapas
- Structs y su composición
- Condicionales y switch
- Bucles y control de iteraciones

### Funciones, métodos y punteros

Trabajé con funciones como ciudadanos de primera clase y con el uso de punteros para entender cómo Go gestiona la memoria.

- Declaración de funciones y retorno de múltiples valores
- Funciones variádicas y funciones anónimas
- Métodos asociados a structs
- Punteros y paso por valor o referencia

### Interfaces y tipos genéricos

Profundicé en la abstracción del lenguaje y en la reutilización de código.

- Definición e implementación de interfaces
- Polimorfismo implícito en Go
- Tipos genéricos y restricciones
- Composición sobre herencia

### Manejo correcto de errores

Aprendí el enfoque idiomático de Go para manejar errores de forma explícita y predecible.

- Retorno y propagación de errores
- Errores personalizados
- Uso de `errors` y `fmt.Errorf`
- Buenas prácticas para no ocultar fallos

### Módulos, paquetes e importaciones

Organicé el código en paquetes y gestioné dependencias con el sistema de módulos de Go.

- Creación y estructura de módulos
- Organización de paquetes e importaciones
- Gestión de dependencias
- Visibilidad de identificadores exportados

### Concurrencia nativa

Exploré el modelo de concurrencia de Go y las herramientas para coordinar tareas de forma segura.

- Goroutines y ejecución concurrente
- Canales para comunicación entre goroutines
- Uso de `select`
- Sincronización con `Mutex` y manejo de contexto con `Context`

### Buenas prácticas

Cerré el curso aplicando convenciones y hábitos para escribir código Go limpio, legible y mantenible: nombres claros, funciones pequeñas, manejo explícito de errores y uso responsable de la concurrencia. El objetivo es asimilar el lenguaje en poco tiempo para dar el salto a proyectos de gran escala.
