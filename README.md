# wqqz.dev — Portafolio personal

Portafolio de **Oswaldo Maguiño**, construido a partir de la plantilla de [imwqqz](https://github.com/imwqqz). Gracias al creador original por compartirla.

## Qué cambié

- Fondo 3D con **Three.js** (`@react-three/fiber` + `@react-three/drei`), persistente entre navegaciones.
- Nueva sección de **proyectos** (`/projects`) con listado, páginas de detalle, imagen de preview y enlace al sitio.
- Las etiquetas ahora combinan archivos y proyectos.
- Tema oscuro único, navegación con blur al hacer scroll y contenido personalizado en español.
- Imágenes reorganizadas en `public/images/`, CV y metadatos del sitio actualizados.
- Eliminé contenido de ejemplo que no utilizo: PGP, scripts y posts de plantilla.

## Stack

Astro, React, Tailwind CSS v4, Three.js y TypeScript.
